# ProcureFlow AI

An AI-powered procurement assistant for industrial purchasing workflows.

## Project Goals

- Validate purchase requests using structured data models.
- Simulate inventory and supplier systems.
- Apply procurement policies and approval rules.
- Orchestrate workflows using LangGraph.
- Integrate tools through MCP.
- Use RAG to retrieve procurement policies and documentation.
- Evaluate reliability through automated tests.

## Current Status

**Phase 1:** Core data models and initial validation tests.

## Tech Stack

Python, Pydantic, pytest, LangGraph, MCP, RAG, FastAPI.

## Disclaimer

All enterprise systems and purchasing operations are simulated. No real purchases are executed.
